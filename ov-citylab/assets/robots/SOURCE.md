# Delivery robots (City Lab)

- `deliveryrobot_001.usd` — sidewalk delivery bot from NEWSMARTCITY
  (`assets/usds/deliveryrobot_001.usd`). Default prim `/deliveryrobot_001`.
- `deliberyrobot_002.usd` — alternate (larger; needs heavier scale).
- `deliveryrobot-001.glb` — source GLB (not referenced by Kit).

Kit loads `deliveryrobot_001.usd` via `CITYLAB_ROBOT_ASSET` /
`CITYLAB_ROBOT_PRIM` / `CITYLAB_ROBOT_MESH_SCALE` (default `0.32`).
